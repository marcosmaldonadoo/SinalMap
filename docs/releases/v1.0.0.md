# SinalMap v1.0.0

Primeira versão distribuída da janela de monitoramento e coleta Wi-Fi para Windows x64, acompanhada da ferramenta de console.

## Recursos

- Monitoramento contínuo do sinal em dBm sem iniciar teste ICMP, com gráfico recente, inspeção de pontos, mínimo e máximo.
- Interface WPF reorganizada, com comandos acessíveis em janelas menores e estados de operação explícitos.
- Gateway IPv4 sugerido a partir da interface selecionada, com destino editável e preservação da escolha manual.
- Varreduras Wi-Fi a cada 5 s na janela, também durante coletas, para atualizar o sinal no perfil de driver em que consultas repetidas permaneciam estáticas.
- Coleta com 60 posições, checagem de rota antes de ICMP, cancelamento com salvamento parcial e análise de JSON local.
- Registro das varreduras e do possível impacto no RTT. A comparação bloqueia diferenças de médias entre políticas de varredura diferentes.
- Pacotes portáteis com .NET incluído e hashes SHA-256.

## Como instalar

Baixe `SinalMap-v1.0.0-win-x64.zip`, extraia todo o conteúdo e abra `SinalMap.Desktop.Wpf.exe`. Para linha de comando, use `SinalMap-Console-v1.0.0-win-x64.zip`. Não é necessário instalar SDK ou runtime .NET separadamente.

## Validação e limites

Compilação Release no Windows x64 e **218 testes automatizados aprovados**. Os testes simulados cobrem agenda, cancelamento, persistência, análise, publicação do sinal, gateway e ciclo de vida das varreduras.

A validação física incluiu deslocamento com MediaTek Wi-Fi 6 MT7921, driver 3.5.0.1349. A coleta corrigida registrou 60 valores de RSSI entre −69 e −24 dBm e 13 confirmações de varredura. O responsável confirmou a variação durante o movimento. Isso comprova a atualização nesse perfil, sem afirmar calibração ou compatibilidade universal.

As varreduras podem aumentar a latência. A consulta em tempo real permanece limitada a um único enlace não MLO; indisponibilidade, códigos nativos e frequência em cache ficam explícitos. O console conserva sua coleta padrão sem varreduras periódicas. O JSON mantém `schemaVersion=1`, com campos opcionais de varredura; leitores antigos podem ignorar o novo aviso.

Os pacotes são portáteis e não assinados, destinados a Windows x64. Plantas, mapas de calor, survey, teste de velocidade e PHY/MIMO/largura de canal não integram esta versão. Os JSONs contêm identificadores de rede e não acompanham os downloads.
